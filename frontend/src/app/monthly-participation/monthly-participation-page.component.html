Open play data

Monthly participation counts from OPParticipation files.

The API scans each month folder under OPParticipation and counts only the names listed under Participants (#) in every text file.

Counting rule

Names in sections like Requested are ignored. A player gets one count each time they appear in a file's Participants list.
